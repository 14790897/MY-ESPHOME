# 门锁控制器 (door-opener-esp32c3)

## 概述

基于 ESP32-C3 + MG946R 舵机的智能门锁控制器，通过 Home Assistant 集成实现远程开关门。

## 硬件

- MCU: ESP32-C3
- 舵机: MG946R (金属齿轮, 50Hz)
- PWM 引脚: GPIO9
- 供电: 外部电源 / 锂电池

## 功能

- `door_open` — 舵机转到 0°，推开门锁
- `door_close` — 舵机转到 180°，关闭门锁
- `door_angle` — 自由角度控制 (0-180°)
- 每晚 22:00 自动进入深度睡眠 10 小时

## 工作原理

舵机推开门锁后 2 秒自动断电 (`auto_detach_time: 2s`)，门锁弹力自动将舵机拉回。这种设计：
- 省电：舵机不持续通电
- 安全：断电后不堵转
- 长寿命：金属齿轮被动旋转无损

## 省电优化报告

### 优化措施

| 措施 | 省电量 | 说明 |
|------|--------|------|
| WiFi `power_save_mode: LIGHT` | ~20-30mA | WiFi 间歇性休眠 |
| 关闭串口 `baud_rate: 0` | ~2-3mA | UART 外设停止驱动 |
| 日志降为 WARN | ~1-2mA | 减少 CPU 处理和 WiFi 发送 |
| 删除冗余 sensor/number 组件 | ~2-5mA | 减少定时更新和 API 推送 |
| `on_boot` 舵机 detach | - | 防止启动时意外堵转 (~200mA) |

### 续航对比

> 两种情况均包含每晚 22:00-08:00 深度睡眠 (10h, ~5μA)

| 指标 | 优化前 | 优化后 |
|------|--------|--------|
| 活跃时段电流 | ~130mA | ~95-100mA |
| 活跃时长 | 14h | 14h |
| 日耗电量 | ~1820 mAh | ~1400 mAh |
| **省电比例** | - | **~23%** |

### 电池续航估算

| 电池容量 | 优化前 | 优化后 |
|----------|--------|--------|
| 2000 mAh | ~1.1 天 | ~1.4 天 |
| 5000 mAh | ~2.7 天 | ~3.6 天 |
| 10000 mAh | ~5.5 天 | ~7.1 天 |

### 进一步优化方向

1. 无活动时自动进入深睡（不仅限于夜间）
2. WiFi `power_save_mode: NONE` + 按需连接
3. 使用 ESP-IDF 框架的 modem sleep 功能
4. BLE 唤醒代替 WiFi 常连接（需 ESP-IDF）
